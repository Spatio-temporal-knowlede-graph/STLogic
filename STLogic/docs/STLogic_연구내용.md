# STLogic 연구 내용 (프로포저용)

> STLogic 제안 방법의 연구 내용 정리 — 논문 프로포저/본문에 인용 가능한 형태.
> 최종 갱신: 2026-07-16. 관련: [PROGRESS.md](PROGRESS.md), 변환기 스펙 `docs/superpowers/specs/`.

## 1. 연구 배경 및 필요성

시공간 지식 그래프(STKG) 상의 link forecasting은 과거 관측을 바탕으로 미래 시점의 누락
링크를 예측하는 과제이다. 임베딩 기반 시간 지식 그래프 모델은 우수한 예측 성능을 보이나,
예측 근거를 사람이 이해할 수 있는 형태로 제시하지 못한다. 이를 보완한 대표적 규칙 기반
모델인 TLogic은 temporal random walk로 시간 논리 규칙을 추출하여 설명 가능한 예측을
제공하지만, 규칙 학습·적용 과정에서 **오직 시간적 관계 순서만 고려하고 객체 간 공간 관계를
반영하지 못한다.**

이 한계는 공간 제약이 강한 도메인에서 심각한 변별력 저하로 이어진다. 하나의 시간 규칙이
수십~수백 개의 후보를 동일한 규칙 신뢰도로 동시에 생성하기 때문에, 규칙 신뢰도와 시간
근접성만으로는 어느 후보가 실제 타당한지 구분하기 어렵다. 따라서 **시간적 패턴과 공간적
타당성을 함께 반영하면서도 예측 근거를 설명할 수 있는 forecasting 프레임워크**가 요구된다.

## 2. 연구 목표

시간 논리 규칙에 **규칙별 공간 맥락 모델(rule-specific spatial context model)**을 결합하여,
설명 가능성을 유지하면서 후보 변별력을 높이는 forecasting 프레임워크 **STLogic**을 제안한다.
핵심은 공간 타당성을 특정 응용 도메인의 지식이 아니라 **좌표계 불변성이라는 일반 원리**에서
도출하여, 어떤 STKG 도메인에도 적용 가능한 방법으로 정립하는 것이다.

## 3. 제안 방법

### 3.1 설계 원리: 좌표계 불변성(frame-invariance)

공간 상의 사실의 타당성은 관측 좌표계의 임의적 선택(원점 위치, 방위 기준)에 의존해서는 안
된다. 즉 장면 전체를 평행이동·회전시켜도 사실의 공간적 타당성은 불변이어야 한다. 따라서
일반적 forecasting 방법이 사용할 수 있는 공간 특징은 **평행이동·회전에 불변인 상대량**으로
한정되며, 절대 위치·절대 방위에 의존하는 특징은 원리적으로 도메인 간 일반화가 불가능하다.
이 원리는 물리·기하의 성질이므로 특정 도메인에 종속되지 않는다.

### 3.2 프레임 불변 상대 공간 특징: 상대 극-운동학 상태 (d, Δd, β)

불변성 원리에서 도출되는 특징은 **움직이는 두 점의 SE(2) 1차 상대 불변량의 완전집합**이며,
모두 엔티티의 위치·시간 정보만으로(속도는 위치 궤적의 차분으로 추정) 계산되어 어떤 STKG에도
적용된다. 즉 빠짐없이, 그리고 더 넣을 것 없이 아래 세 성분으로 정해진다.

| 특징 | 성격 | 필요 정보 |
|---|---|---|
| 거리 d | 상대 위치의 유일한 회전·평행이동 불변량 | 위치 |
| 접근율 Δd | d의 시간 미분(상대 반경 속도) | 위치 + 시간 |
| 상대 방위 β | 주체의 운동방향 기준 대상 각도 | 위치 궤적 |

이 세 값은 특정 관계만 돕는 부분 특징이 아니라 **데이터의 모든 관계 유형의 공간적 의미를
구분하는 기하 서명**이다. 예: movesToward(Δd<0, β≈0)와 withdrawsFrom(Δd>0, β≈180)은 거리
하나로는 구분되지 않으나 Δd 부호와 β로 갈리며, follows(근접·동일축)·occupies(d≈0)·firesAt
(교전거리)도 이 세 축 위에서 분리된다.

**전 관계 균일 적용**: 대상 위치를 지형(정적 좌표)·엔티티(관측 좌표)·부대(구성원 중심점)로
일관되게 정의한다. 정의되지 않는 성분(정지 상태 → β 없음, 좌표 없는 대상 → 공간항 없음)은
자연 생략되어 기존 시간 규칙 예측으로 환원된다.

절대 위치·지형 구역 특징은 프레임 종속이라 코어에서 제외하고, **전이성 대조를 위한 비교
(ablation) 대상**으로만 사용한다.

### 3.3 공간 맥락 모델 학습 및 결합

- **학습**: 각 시간 규칙의 grounding 사례를 수집하여, 상대 극-운동학 상태 (d, Δd, β)의 결합
  분포를 Gaussian으로 모델링해 규칙별 평균·분산(μ, σ)을 추정한다.
- **추론**: 규칙 grounding으로 생성된 각 후보에 대해 현재 상대 특징을 계산하고, 해당 규칙의
  공간 분포와 비교하여 spatial fit score를 산출한다.
- **결합**: spatial fit score를 규칙 신뢰도·시간 근접성 점수와 결합해 grounding score를
  보정하며, 최종 후보 점수는 기존과 동일한 **Noisy-OR 집계**로 산출한다.
- **분산 기반 자동 관련성 게이팅(핵심)**: 어느 관계에 공간 점수를 줄지 사람이 지정하지 않는다.
  규칙별로 학습된 σ가 관련성을 자동 조절한다 — partOf·supports처럼 공간 규칙성이 없는 조직적
  관계는 grounding의 (d, Δd, β)가 산포되어 σ가 커지고 fit이 평탄해져 영향이 사라지며, firesAt·
  movesToward처럼 기하적으로 규칙적인 관계는 σ가 작아 강한 변별력을 갖는다. 따라서 전체 관계에
  균일하게 적용하되 비기하 관계를 왜곡하지 않는다.
- **스트리밍 누적**: μ, σ는 running statistics로 새 장면(섹터)이 유입될 때마다 증분 갱신할 수
  있다. 상대 특징이라 장면을 넘어 분포를 합칠 수 있어(절대 좌표로는 불가능) 지속 유입 데이터에
  구조적으로 부합한다. (관측 오차·다중센서·dangling에 대한 confidence 가중은 견고성 옵션.)

## 4. 차별성(Novelty)

- **기존 TLogic 대비**: 시간 순서에 더해 규칙별 상대 공간 분포를 반영하여, 동일 규칙이 생성한
  다수 후보를 공간적으로 변별한다. 설명 형태는 "어떤 시간 규칙이 적용되었으며 그 후보가
  공간적으로 왜 타당한지"로 확장된다.
- **기존 STKG 임베딩(예: STSE) 대비**: 이들은 절대 좌표를 잠재공간에 학습하여 장면 종속적·
  transductive하며 설명이 어렵다. STLogic은 **프레임 불변 상대 공간분포를 규칙별로 명시적으로
  학습**하므로 설명 가능하고, 학습 장면에 없던 test 장면으로 전이되는 **inductive** 예측이
  가능하다.
- **분산 자동 게이팅**: 규칙별 σ가 공간 관련성을 스스로 조절하여, 전체 관계에 균일 적용하되
  비기하 관계는 자동 무력화된다. 어떤 관계에 공간을 반영할지 수작업으로 고르지 않는다는 점이
  기존 방식과 구분되는 설계적 novelty이다.
- **일반성·확장성**: 방법이 전장 도메인 지식이 아니라 불변성 원리에서 도출되므로 위치·시간을
  갖는 임의의 STKG(교통·역학·물류·이동성 등)에 그대로 적용되며, 상대 특징의 분포는 지속 유입
  데이터에서 온라인 누적·전이가 가능하다.

## 5. 실험 설계

- **데이터셋**: 자체 구축한 전장 STKG(백마고지, battlefield_hill395). 75개 독립 장면(섹터)을
  train/dev/test로 사전 분할하여, 학습 장면의 규칙을 미지의 test 장면에 적용하는 **inductive
  forecasting** 설정으로 평가한다. 각 관측은 시간별 위치·상태·관계를 포함한다.
- **평가 지표**: MRR, Hits@1, Hits@3, Hits@10 (시간 정보를 고려한 filtered setting).
- **비교군**:
  - 규칙 기반: TLogic(공간 미고려, 직접 비교 대상; 예비 baseline MRR 0.625).
  - (검토) 임베딩·STKG 기반: RE-Net, CyGNet, TiRGN, STSE.
- **Ablation(핵심 검증)**: 특징 계층을 단계적으로 비교한다.
  `공간 미적용(=TLogic)` → `거리` → `거리+Δd` → `거리+Δd+상대방위` → `(대조군) +절대 위치`.
  이를 통해 (i) 상대 공간 특징의 기여와 (ii) 절대 공간 특징이 inductive 설정에서 전이되지
  않음을 실증하여, 상대 특징 선택의 당위성을 데이터로 뒷받침한다.
- **Case study**: 동일 시간 규칙이 생성한 다수 후보에 대해 TLogic과 STLogic의 순위 변화와
  공간적 근거를 비교하여 설명 가능성을 정성 분석한다.

## 6. 기대 효과

시간 규칙 기반 설명 가능성을 유지하면서 규칙별 공간 타당성을 반영해 예측의 현실성·신뢰도·
설명력을 높인다. 공간 타당성을 도메인 특화 규칙이 아니라 좌표계 불변성 원리로 정립함으로써,
전장뿐 아니라 위치·시간을 갖는 다양한 시공간 지식 그래프에 포괄적으로 적용 가능한 설명 가능·
inductive forecasting 기술을 확보한다. 근거 추적이 요구되는 의사결정 지원 환경에 활용 가능하다.

### (참고) 구현·검증 개요 — 프로포저 본문 외
- 코드 수정은 `STLogic/mycode/`에서만 수행하고 `TLogic/`은 순정 baseline으로 보존.
- 학습 시 전체 상대 특징을 fit하여 규칙에 (μ,σ)를 부착·저장하고, 추론 시 특징 부분집합을
  선택해 한 번의 학습으로 전체 ablation을 수행. Noisy-OR 집계 구조는 불변.
- `--spatial off`가 순정 TLogic 수치와 일치함을 회귀로 확인해 코어 로직 무변경을 보증.
